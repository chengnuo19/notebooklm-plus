复习概览与设置

查看各 Notebook 的错题数量和累计复习表现。统计仅保存在浏览器本地。

Notebook 复习统计

复习设置

移出错题本所需的连续答对次数 复习时，错题连续答对达到此次数后，将自动从错题本中移除。

Obsidian 集成设置

Vault 名称 目标 Obsidian Vault。支持一键将内容导出到该仓库。
默认文件夹 (可选) 如果填写，导出的笔记将默认放置在该文件夹内。

Notion 集成设置

Integration Token 你的 Notion 内部集成 Secret Token (以 secret_ 开头)。
目标页面链接或 ID 导出内容会成为该页面的子页面。需先把目标页面共享给 Integration。
目标类型 当前链接是普通页面；数据库目标仍可继续使用。
自动同步错题 在测验中答错的题目，自动在后台单向同步到目标。
自动同步好题 点击“⭐️ 收入好题”时，自动在后台单向同步到目标。

出题模板管理

自定义快捷出题的系统提示词模板，插件会自动用选项替换模板中的 {{types}}、{{count}}、{{difficulty}}、{{scope}} 和 {{language}} 占位符。

AI 服务配置

配置外部 AI 模型，用于分析错题和复盘。API Key 本地保存，不跨设备同步，也不会传递给页面脚本。

服务商设置

服务商 选择用于生成 Quiz 复盘的 AI 模型服务。
API Key 服务商的 API Key (例如 sk-...)。
自定义模型名称 (可选) 留空则使用服务商默认模型 (例如 deepseek-chat)。

本地复习数据

错题与累计统计均保存在浏览器扩展的本地存储中，不会上传至任何云端服务器。
